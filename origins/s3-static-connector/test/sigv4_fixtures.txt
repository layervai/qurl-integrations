# SigV4 / canonicalization regression fixtures for s3-static-connector.
# behavior_test.sh uses real nginx + Envoy and a signature-verifying S3 stub.
# The verifier has AWS's published S3 GET vector and independently captured
# AWS CLI S3 GetObject signatures for spaces, plus, slash, literal %2F and //.
# Forged signatures, changed paths/methods/headers and query leakage fail.
# Synthetic credentials only: this establishes canonical signing, not IAM/TLS.
# [crypto] = S3 fixture verifies the HMAC before selecting the key.
# [rejected] = viewer 404 with no S3 GET; unsafe/unsupported decoded key bytes.
#
# request-path              -> S3 key path / outcome                    [status]
/                           -> /index.html                                [crypto]
/website                    -> /website/index.html                        [crypto]
/website/                   -> /website/index.html                        [crypto]
/metrics.json               -> /metrics.json                              [crypto]
/metrics.json?_t=123         -> /metrics.json (query stripped)             [crypto]
/v1.2/docs                  -> /v1.2/docs (dot suppresses rewrite)         [crypto]
/about.                     -> /about.                                    [crypto]
/deep/path                  -> /deep/path/index.html                      [crypto]
GET /range.bin Range: 0-3    -> 206 partial                                 [crypto]
HEAD /metrics.json          -> 200 no body                                 [crypto]
/a+b.txt                    -> /a+b.txt                                   [crypto]
/a%2Bb.txt                  -> /a+b.txt (encoded plus)                    [crypto]
/a%2Fb.txt                  -> /a/b.txt (encoded slash is a separator)    [crypto]
/dir//file.txt              -> /dir/file.txt (nginx merges slashes)       [crypto]
/a%20b.txt                  -> 404; spaces unsupported                    [rejected]
/a%252Fb.txt                -> 404; literal percent/escape unsupported    [rejected]
/a%25252Fb.txt              -> 404; nested percent escape unsupported    [rejected]
/a%25b.txt                  -> 404; literal percent unsupported           [rejected]
/a%3Fb.txt                  -> 404; literal question mark unsupported     [rejected]
/a%23b.txt                  -> 404; literal hash unsupported              [rejected]
/caf%C3%A9.txt              -> 404; non-ASCII unsupported                 [rejected]
